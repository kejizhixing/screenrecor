# 屏幕录制专家

一款轻量、易用的 Windows 桌面屏幕录制工具，支持高清录屏、滚动文字、图片水印、自定义壁纸、放大镜与点击特效，适合制作教程、演示与日常记录。

---

## 主要功能

- **高清屏幕录制**：可选的录制区域（全屏 / 窗口 / 自定义区域），输出清晰流畅的 MP4 视频。
- **滚动文字**：在画面上叠加滚动文字，支持导入文本文件、多行换行滚动、自定义位置（顶部 / 底部任务栏上方 / 自由飘浮）与背景透明度。
- **图片水印**：支持使用自带或自定义的图片作为水印叠加到视频中。
- **自定义壁纸**：录制前可一键切换桌面壁纸，录制结束后自动恢复原壁纸。
- **放大镜与点击特效**：录制时显示鼠标滚轮放大镜与点击光晕，可选是否一并录进视频，方便制作操作教程。
- **多音轨混音**：系统声音、麦克风、背景音乐三路独立音量控制，自由搭配。
- **最近录制管理**：录制完成后可快速播放、打开所在文件夹、导出 GIF、提取音频、删除（走回收站，不误删）。
- **主题切换**：提供浅色 / 柔和 / 深色三种界面主题，设置自动记忆。
- **托盘与悬浮图标**：最小化到托盘，桌面悬浮图标单击暂停/继续、双击停止，操作不打断录制。

## 安装与运行

1. 从发布包中下载对应版本（自包含版或轻量版）。
2. 将文件夹解压到任意位置（建议路径不含中文与空格）。
3. 双击 `ScreenRecorderCs.exe` 启动程序。

> 提示：ffmpeg 等必要组件已随软件一同打包，无需单独安装。

---

## 快速上手

1. 启动后，主窗口停靠在屏幕顶部，可拖动到任意位置。
2. 点击「开始录制」即可录制；再次点击暂停/继续，双击停止。
3. 在「设置」中可配置输出目录、滚动文字、图片水印、壁纸、音频与主题等。
4. 录制完成后，在「最近录制」中管理生成的视频。

## 常见问题

**Q：录制没有声音？**
A：请检查「设置」中的音频来源与音量，系统声音需在电脑有声音输出时才会被录制。

**Q：轻量版提示缺少运行库？**
A：轻量版需要 .NET 8 桌面运行时，请先安装；或直接改用自包含版（无需运行库）。

**Q：视频文件在哪里？**
A：默认保存在「视频 / 屏幕录制专家」文件夹，可在「设置」中修改输出目录。
